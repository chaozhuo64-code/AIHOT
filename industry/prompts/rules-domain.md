
【金融领域翻译与写法规则 — 本平台 100% 是金融/财经行业内容，严格遵守】

1. 歧义默认值：以下词在中文有非金融歧义，**一律按金融含义理解与翻译**：
   - 头寸 = 持仓或资金缺口（绝不译"位置"）
   - 做多 / 做空 = 看涨买入 / 看跌卖出（不译"长"/"短"）
   - 敞口 = 风险暴露（不译"开口"）
   - 杠杆 = 借用资金放大投资敞口（不译物理学含义）
   - 久期 = 债券久期（不译"持续时间"）
   - 贴现 = 票据贴现或现金流折现（按上下文，不译"打折"）
   - 溢价 / 折价 = 相对净值或面值的溢价 / 折价
   - 对冲 = 风险对冲（不译"树篱"）
   - 清算 / 结算 = 金融清算与结算
   - 托管 = 资产托管（不译"寄存"）
   - 承销 / 保荐 = 证券承销与保荐
   - 配股 / 增发 / 定增 = 再融资方式，三者不混用
   - 质押 / 抵押 = 按担保方式区分，不混用
   - 降准 / 降息 / 加息 = 货币政策操作，不译成"降低标准""减息""提息"
   - 通胀 / 通缩 = 物价水平变化
   - 平仓 / 爆仓 = 期货与杠杆交易状态（不译"关闭仓库"）

2. 机构、交易所与指数**用官方中文名**，首次出现可双标英文，之后保持一致：
   - 监管与政府：中国人民银行（央行）/ 国家金融监督管理总局（金融监管总局）/ 中国证监会 / 财政部 / 国家统计局 / 国家外汇管理局
   - 交易所：上海证券交易所（上交所）/ 深圳证券交易所（深交所）/ 北京证券交易所（北交所）/ 香港交易所（港交所）
   - 海外机构：美联储（Federal Reserve）/ 欧洲央行（ECB）/ 日本央行（BOJ）/ 国际货币基金组织（IMF）
   - 指数：上证指数 / 沪深 300 / 中证 500 / 创业板指 / 科创 50 / 恒生指数 / 标普 500 / 纳斯达克综合指数 / 道琼斯工业平均指数
   - 海外媒体与机构名（Bloomberg / Reuters / FT / WSJ / Nasdaq / NYSE / S&P Global 等）保留英文，不做硬译

3. 数字、比例与量词 **一字不改**保留：
   - 百分比、基点（bp）、亿元 / 万元 / 亿美元、同比 / 环比 / 累计，一律保留原文数字与量词
   - 利率、收益率、汇率保留原文精度（如 1.75%、7.12、+32bp），不四舍五入、不换算
   - 时间口径保留原文写法（"前三季度""2026 年上半年""截至 9 月末"），不改写成概略说法
   - 不要把"1.2 万亿元"改写成"逾万亿"，也不要把"同比下降 3.4%"改写成"小幅下滑"

4. 代码、产品名与文件名 **一字不改**保留：
   - 股票、债券、基金代码原样保留（如 600519.SH、019666、159915）
   - 产品与规章全称保留（如《公开募集证券投资基金运作管理办法》、"沪深 300ETF 联接"）
   - 条款中的期限、档位、费率档位必须原样保留

5. 描述行情时**不替原文下结论**：
   - 原文说"下跌"就写下跌，不改写成"回调""调整"；原文说"上涨"就写上涨，不改写成"走高""拉升"
   - 不使用"利好""利空""抄底""上车"等评价或鼓动词，除非原文本身使用
   - 不把机构预测写成既成事实，预测一律标明是预测或观点
